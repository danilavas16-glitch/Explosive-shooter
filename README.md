# 💥 BoomArrows (Minecraft 26.2 Fabric)

![Minecraft Version](https://shields.io)
![Mod Loader](https://shields.io)
![License](https://shields.io)

**BoomArrows** adds craftable **Explosive Arrows** to Minecraft 26.2 with a custom fire-and-smoke trail in mid-air and a multi-layered shockwave explosion on impact!

> 🎥 *Tip: Record a 5-second GIF of shooting an arrow at night and replace this line with `![Demo](demo.gif)`!*

---

## ✨ Features
* **Explosive Arrows:** Compatible with all standard Bows and Crossbows.
* **Custom Flight Trail:** Leaves behind glowing `FLAME` and `SMOKE` particles while flying.
* **Multi-Layered Explosion:** Triggers a flash, shockwave smoke ring, lava sparks, and heavy explosion sound on impact.
* **Survival Friendly:** Easy to craft on any Crafting Table.

---

## 🛠️ Crafting Recipe
Combine **1 Arrow** + **1 Gunpowder** in any slot of a Crafting Table (shapeless recipe) to get **1 Explosive Arrow**.

---

## 📥 Installation
1. Install **[Fabric Loader](https://fabricmc.net)** for **Minecraft 26.2**.
2. Download **[Fabric API](https://modrinth.com)** for **26.2** and put it into your `.minecraft/mods` folder.
3. Download the latest `boomarrows-x.x.x.jar` from the **[Releases](../../releases)** tab on the right.
4. Drop `boomarrows-x.x.x.jar` into your `.minecraft/mods` folder and launch the game!

---

## 💻 Building from Source
```bash
chmod +x gradlew
./gradlew build
```
The compiled `.jar` will appear in `build/libs/`.
